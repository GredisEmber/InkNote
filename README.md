# InkNote

一个**个人自用**的 Android 手写笔记 App。为联想 Y700 平板 + 支持压感和侧键的手写笔写的。

不上架、无后端、无云同步、无登录。所有数据都在设备本地。

## 已实现

### 书写

- **钢笔**：真实压感变宽，带笔锋。四支可调滑块（见下）
- **荧光笔**：半透明、等宽，**画在钢笔下面** —— 涂在已有的字上时字会透出来
- **橡皮**：笔迹级擦除，整笔删掉
- **侧键**：单击手写笔侧键切换钢笔/橡皮

### 笔的设置（二级 + 三级面板）

点一下工具选中，**再点一下**弹出窄菜单；菜单里的项再点开三级窗口。

| 项 | 内容 |
|---|---|
| 颜色 | 3 个预设（墨黑/红/蓝）+ 1 个自定义槽位；自定义支持色相/饱和度/明度三滑块 + 十六进制输入 |
| 粗细 | 基础粗细、压感灵敏度、压感强度、平滑度，**带试写区**可以立刻试笔 |

**每支笔的颜色互相独立** —— 换钢笔颜色不会把荧光笔改掉。

四支滑块的映射经过设计：**全部居中（0.5）时的手感和改版前手调的参数逐位相同**。

### 笔记与页面

- 纸型：A4 / A3 / 与屏幕相同，各支持横竖（创建时选定，之后不可改）
- 多页：新建、复制、删除、上下排序
- 书签：标记 + 短标签，可只看书签（此时禁用排序）
- 缩略图：首页卡片和页列表都显示真实笔迹缩略图，缺失时自愈重建

### 阅读与导航

- **无缝连续滚动**：多页纵向排布，可以停在两页之间同时看到上一页和下一页
- **滚动吸附**：可选（默认关），开启后松手对齐整页
- 翻页方式：左右滑动（整页切换）/ 上下滑动（无缝滚动）

### 设置

翻页方式、滚动吸附、只认手写笔、显示笔迹信息（诊断用）

- JDK **21**（Android Studio 自带的 JBR 缺 `jmods`，会报 `jlink.exe` 失败 —— 用独立 JDK）

## 几个值得说明的设计决定

### 颜色存 ARGB，不存调色板下标

删掉调色板里的某个颜色之后，用那个颜色写的旧笔记**颜色不会变**。如果存的是下标，删色会让历史笔记的颜色悄悄改变，而用户根本没动过它们。

### 纸张永远是浅色

笔迹存的是写入时的颜色。如果纸色跟着深色主题走，会出现"浅色下写的黑字 → 切深色 → 黑字在黑纸上"，历史笔记直接看不见。主题只影响界面外壳。

### 荧光笔必须画在下层

单个位图无法做到"荧光笔透出下面的字"。而"每次落点整页重画"会让书写卡死。所以画布分两层：**下层纸+荧光笔，上层钢笔**。

上层**按需分配** —— 页面上没有荧光笔时不分层，钢笔直接画在下层。这让每页的内存开销减半（A3 约省 17MB）。

### 笔宽用文档短边的比例，不用毫米

A4 竖版会缩到 0.8 倍显示。如果按绝对毫米定义，A4 上的"细笔"在屏幕上只有 3px，完全不可用。按比例定义，**线宽占纸面的比例恒定** —— 而这正是眼睛判断粗细的依据。

### 每页一个文件，文件名用 pageId 而不是序号

排序和删除都不需要改文件名。

## `.ink` 文件格式（v2）

```
┌─ 16 字节头 ─────────────────────────────┐
│ magic   u32   0x494E4B31 "INK1"         │
│ version u8    2                         │
│ reserved      3 字节（留作扩展）         │
│ crc32   u32   正文的校验和               │
│ length  u32   正文字节数                 │
├─ 正文 ──────────────────────────────────┤
│ pageWidth   f32                         │
│ pageHeight  f32                         │
│ strokeCount varint                      │
│ 每笔：                                   │
│   colorArgb  i32                        │
│   widthPx    f32                        │
│   style      u8                         │
│   tool       u8    0=钢笔 1=荧光笔（v2新增）│
│   pointCount varint                     │
│   点：绝对坐标打头，之后用增量 + zigzag  │
└─────────────────────────────────────────┘
```

- 坐标是 **1/4 像素定点数**（`COORD_SHIFT = 2`），压力是 **1/1024** 定点
- 增量 + zigzag 编码让体积压到约 **3 字节/采样点**
- **v1 文件能正常读取**（没有工具字节，按钢笔处理）—— 已用真实旧笔记在设备上验证
- 未知的更高版本会明确报"请升级 App"，而不是静默返回空页面

## 已知限制

- **侧键**只能靠真机 + logcat 验证。adb 注入的按键事件会被系统丢弃，`sendevent` 需要 root
- **手写笔接触屏幕时**，联想的 ZUI 会抑制注入的触摸事件，所以自动化测试无法在笔悬停时操作界面
- 无缝滚动模式下页与页之间有较大的视觉留白（页面在画布里居中留边导致）
- 缩略图是缓存，靠 `page.updatedAt` 失效 —— 不是每次改动都实时重建
